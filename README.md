# 小屋大亨 — 問答賺錢蓋房子

答題賺錢 → 買建材擴建房屋 → 買服飾與家具 → 佈置房屋 → 拜訪/按讚/排行。

## 執行
```bash
npm install
npm start          # 預設 http://localhost:3000（PORT 可用環境變數改）
```
需要 Node 22+（使用內建 `node:sqlite`）。存檔在 `data/game.db`（可用 `DATA_DIR` 改位置）。

## 玩法重點
- 帳號登入（密碼以 scrypt 雜湊），金錢/經驗/房屋/倉庫都存在伺服器。
- 問答：10 題選擇題、參加費 50。線上配對（10 秒無真人由電腦頂替）或邀請碼好友對戰。
- 新手（Lv ≤ 4）連答倍率 ×1.6（+60%），老手 ×1.2（+20%）；新手可與任何人對戰。
- 倉庫放建材，50 格，每升級 +5 格；房屋擴建需要金錢 + 建材。賣出價 35%。
- 房屋風格 ≥80% 且 ≥6 件，答題金錢 +5%。
- 排行榜（勝場/連擊/人氣/等級/活躍）、拜訪與按讚。
- 題目有「全站答對率」、近期見過的題會盡量避開、可回報有誤（寫入 `reports` 資料表）。

## 檔案
- `server.js` 伺服器；數值參數在最上方 `CFG`
- `questions.js` 題庫（手寫題 + 程式生成題 + 匯入 `data/questions/*.json`）
- `catalog.js` 商品目錄
- `public/index.html` 前端
- `Dockerfile` 部署用（需掛載 `/data` 並使用支援 WebSocket 的主機）

## 匯入大量題庫
放 JSON 到 `data/questions/`：`[{"c":"地理","q":"題目","a":"正解","w":["錯1","錯2","錯3"]}]`
