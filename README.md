# 小屋大亨 — 問答賺錢蓋房子（3D 版）

答題賺錢 → 買建材擴建房屋 → 買服飾與家具 → 在 **3D 房間**自由擺放 → 更衣室試穿 → 拜訪/按讚/排行。

## 執行
```bash
npm install
npm start          # 預設 http://localhost:3000（PORT 可改）
```
需要 Node 18+（22+ 用內建 SQLite 存檔，較舊版本自動改用 JSON 檔）。存檔在 `data/`（`DATA_DIR` 可改；設定 `DATABASE_URL` 則存到 Postgres）。
**免安裝單機版**：`npm run build` 會產生 `dist/小屋大亨.html`（單一檔案，雙擊即可玩，無線上對戰）與 `docs/index.html`（GitHub Pages 用）。
**免費部署**：見 [DEPLOY.md](DEPLOY.md)（GitHub Pages 單機版／Render + Neon 多人連線版）。
測試用：`START_MONEY=30000`（初始金額）、`TIME_SCALE=60`（城市時間加速：1 分鐘＝1 小時）、`START_LEVEL=20`（建立老手帳號）。

## 玩法重點
- 帳號登入（密碼 scrypt 雜湊）；註冊時取名免費，**改名要 100,000 元**（更衣室頁面）。
- **Q 版古代武俠角色**，初始服裝（青衫劍客／白衣俠女）免費配發，可隨時換回。
- **自宅**：3D 房間自由擺放家具、換牆壁地毯，可擴建。
- **城市**：先買一塊地，再蓋 5 種住宅（收租）或 8 種商業建築（便利商店、餐廳、學校、按摩店、KTV、診所、公司、百貨公司）。**商業建築要雇用管理者才有產值**：管理者有 1～5 星能力與專長，專長對口效率 ×1.25，但要付薪水。建築可升級到 5 級、可拆除退款。產值隨時間累積（最多 12 小時），回來「收取」。
- **遊樂場**：問答對戰（10 題）、猜歌詞對戰（真正的歌曲歌詞：傳統童謠／民謠／國歌／英文經典兒歌＋歌手與電影配樂小知識）、踩地雷（3 種難度）、記憶翻牌、猜數字 1A2B、**切水果**（初／中／高級，參加費 30、限時 60 秒、水果越來越多、不同水果不同分數、切到炸彈就爆炸輸掉，贏了 +300 元，經驗 50／60／72）、**三格打殭屍**（3 條通道；殭屍走過一半才能點，亂點扣 1 條命）；踩地雷右鍵直接插旗（手機長按）。連擊只計算「連續答對」，中途答錯就重新計算；結算畫面按「再來一場」會直接用同樣的玩法再開一局。小遊戲的輸贏由伺服器「重播」你的操作驗證，每種每天最多領 5 次獎勵。
- **問答選項**：所有題目都是四選一，錯誤選項與答案同類型（人物配人物、山配山、顏色配顏色…）。
- **連答倍率**：預設 ×1.2。**新手（Lv ≤ 15）遇到老手（Lv ≥ 16）時，新手的倍率才變 ×1.6**；雙方都是新手、或對戰電腦，一律 ×1.2。
- **按讚**：按讚的人 +5 元（每人只能讚同一玩家一次；每天最多領 5 次獎勵）。
- 倉庫放建材 50 格，每升級 +5；房屋擴建要金錢 + 建材。賣出價 35%。每件商品有持有上限。服飾只在更衣室販售。
- 房屋風格 ≥80% 且 ≥6 件，答題金錢 +5%。

## 題庫（1,100 題）
- 手寫題 1,028 題（地理、天文、歷史、會計、護理、科學、生物、生活常識、體育、文學藝術、科技、國文、社會、英文單字與文法、哲學、腦筋急轉彎、猜歌詞），程式生成的數學計算題 72 題。
- **不是從網路抓來的考古題**（開發環境的網路政策擋住了考試單位網站）；腦筋急轉彎、哲學等都是我自己整理撰寫。要匯入考古題請看下一節。
- **選項品質**：每題的錯誤選項都和答案同一類型。有的是手寫指定（`qbank_wrong.js`、腦筋急轉彎與猜歌詞每題都手寫了選項），其餘依「同類名單」（`qgroups.js`：人物、山、河流、縣市、元素、單位…）自動挑選。搞笑選項預設關閉（`FUNNY_RATE=0.3` 可開啟）。
- 猜歌詞只收公共領域歌曲的歌詞（流行歌歌詞有著作權，本專案不內建）。想加入自己的歌詞：照 `templates/lyrics.csv` 的格式（歌名,句子含____,答案,錯1,錯2,錯3）存成 `data/lyrics/*.csv`，重開伺服器即可載入。古詩詞填空獨立成「詩詞填空」類別。
- 房屋比最初版大 3 倍（Lv.1 為 18×12 公尺），角色可在房內走動：點地板空白處走過去，或用 W A S D／方向鍵。點椅子／沙發可「坐下休息」（每 1 小時 +1 經驗），點床可「睡覺」（+20 經驗，每天 2 次）。坐下後可讀書（需有書：商店「古風」擺飾）／打電腦／看電視，每次 +5 知識點；答題時 30 點可刪 1 個錯誤選項、60 點可直接答對。
- 全部題庫可下載：`downloads/question-bank.csv`、`question-bank.json`（`node tools/export-bank.js` 重新匯出）。

### 匯入考古題
1. 從考試單位下載試題與答案 PDF，轉成文字：`pdftotext -layout 試題.pdf 試題.txt`、`pdftotext -layout 答案.pdf 答案.txt`
2. `node tools/import-exams.js 試題.txt 答案.txt --cat 國文 --src "112學測國文"` → 產生 `data/questions/*.json`，重啟伺服器即載入。
3. 另可直接放 JSON/CSV 到 `data/questions/`（CSV 欄位：`分類|標籤,題目,答案[,錯1,錯2,錯3]`）。
> 各單位對試題轉載的授權規定不同，營運前請自行確認。
